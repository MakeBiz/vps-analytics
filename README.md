# Сквозная аналитика по сайтам-каталогам

Единая панель на четыре сайта: визиты, метки, переходы к провайдерам.

## Что нужно задать в Vercel

- `DATABASE_URL` — строка подключения к Postgres (Neon из маркетплейса Vercel подставляет её сам)
- `ADMIN_PASSWORD` — пароль на вход в панель

После добавления переменных сделайте Redeploy. Таблицы создаются сами при первом обращении.

## Как подключить сайт

В `vercel.json` сайта:

```json
"rewrites": [
  { "source": "/px/:path*", "destination": "https://<адрес панели>/px/:path*" }
]
```

В `<head>` каждой страницы:

```html
<script defer src="/px/t.js" data-site="КЛЮЧ_САЙТА"></script>
```

Переходы по внешним ссылкам счётчик ловит сам: провайдер определяется по хосту назначения,
место — по `utm_campaign` партнёрской ссылки, кнопка — по её тексту.
